🗓️ 단계별 계획
  • 1단계 (1~2주) — 홈 3단 위계(오늘의 작업 → 퀵 액션 → 입항·공지) + FAB 1개 선배포
  • 2단계 (3~4주) — 5탭 전환(홈/근무/선박/터미널/더보기), 근무일지 3단계 스텝 플로우, 통합 검색·알림 센터, 인라인 스타일 70% 정리
  • 3단계 (2~3주) — 뒤로가기·렌더 최적화, HTML 내 함수 모듈화, 자동화 테스트 보강 및 목표 지표 검증
