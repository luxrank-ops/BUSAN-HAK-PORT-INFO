## 3. 개선 원칙 (모든 개선안의 공통 전제)

1. **디자인 불변**: 색·간격·타이포·라운드·그림자·모션 토큰을 변경하지 않는다. 새 시각 요소(새 배지·새 모달 스타일)를 만들지 않고, **기존 토스트·배지·문구 컴포넌트를 재사용**해 안내를 추가한다.
2. **한 번에 한 축**: 한 PR = 한 방향(A~E 중 1개). 정산 로직 변경과 화면 정리 변경을 섞지 않는다.
3. **측정 가능**: 모든 개선은 §7의 지표로 전후 비교한다. "좋아진 것 같다"는 판정 불가로 간주.
4. **회귀 방지 우선**: 새 기능 추가보다 **기존 기능이 조용히 깨지지 않게** 하는 작업을 먼저 한다.
5. **되돌리기 쉬운 단위**: 각 개선은 독립적으로 revert 가능하게(설정 플래그 또는 별도 PR) 진행한다.
6. **CI 통과가 완료 조건**: 모든 변경 후 `npm run check` 통과 + 관련 테스트 추가.

### 이번 단계에서 드러난 사실 (운영 참고)

1. **관리자 비밀번호 세션은 규칙상 관리자(`isAdmin()`)로 인정되지 않습니다.** `admins/{uid}` 문서를 만들려면 이미 관리자여야 하는데(순환 구조), 그 문서를 만들려는 코드가 화면에 있어 실제로는 생성이 거부됩니다. 그 결과 **공지 수정·삭제, 자료실 삭제, 선박 물리 삭제 같은 관리자 전용 기능은 "권한 없음"으로 실패**합니다(이번 변경 전에도 동일).
   → 해결은 C-4(실제 로그인 계정) 과 함께 `admins` 문서를 콘솔/관리자 도구에서 등록하는 방식이 맞습니다.
2. **선박 정보 삭제가 이제 정상 동작합니다.** 예전에는 규칙이 관리자 전용이라 누구도 삭제할 수 없었습니다(오류 표시). 이제는 작성자가 소프트 삭제할 수 있습니다.
3. **남은 한계(테스트에 명시)**: `work_logs` 목록 조회는 **workerId 조건을 넣은 쿼리라면 누구나** 실행할 수 있습니다(`where('workerId','==','남의ID')` 도 허용). 화면은 본인 것만 요청합니다. 규칙으로 막으려면 소유자와 인증 계정을 연결하는 로그인 모델이 필요합니다 → C-4·D-4.
4. **규칙은 필터가 아닙니다.** 규칙이 `resource.data.workerId` 를 검사하므로, 목록 조회는 **workerId 조건을 증명할 수 있어야** 허용됩니다. 날짜 범위만 걸린 조회(인덱스 미배포 시의 옛 방식)는 규칙 엔진이 거부합니다 → 화면의 대체 조회도 **workerId 조건을 유지하고 날짜는 화면에서 거르는 방식**으로 바꿨습니다(에뮬레이터 테스트로 두 경우 모두 고정).
5. **관리자용 전체 조회**(누적 근무일지 등)는 규칙상 실제 관리자 로그인(C-4)이 필요합니다. 지금은 권한 오류 메시지를 표시하도록 되어 있고, 규칙에는 `isAdmin()` 경로를 열어 두었습니다.

### 이번 단계에서 드러난 사실 (개발 참고)

1. **`js/*` 폴더는 과거에 인라인 코드를 "미러링"해 두었다가 갱신하지 않은 것이었습니다.** `worklog.js`·`lazy-d3.js` 등은 인라인과 세부 구현이 이미 갈라져 있었습니다(동기화 테스트가 그 사본을 지킵니다). 그래서 "미사용 파일 재활용"이 아니라 **실행 중인 인라인을 추출해 정본으로 삼고 사본을 삭제**하는 방향으로 했습니다.
2. **테스트 인프라가 코드 위치 변경을 흡수하는 패턴을 확정했습니다.** `scripts/app-source.mjs` 가 전역 JS 를 합쳐 읽고, `extractFunction()`(매개변수 괄호·문자열 인식 추출기) 과 `extractDeclaration()` 을 제공합니다. 인라인 시절 8개 테스트가 HTML 에서 코드를 꺼내던 방식은 이 헬퍼로 대체했습니다 — 다음에 위치가 바뀌어도 테스트는 헬퍼만 고치면 됩니다.
3. **app.css 는 이제 디자인 토큰 검증의 정본입니다.** `tokens:apply` 가 `css/app.css` 를 갱신하고 `tokens:check` 가 이를 검사합니다(과거에는 index.html 인라인 스타일을 검사). 인라인 `<style>` 이 다시 생기면 `app-split.test.mjs` 가 실패합니다.
