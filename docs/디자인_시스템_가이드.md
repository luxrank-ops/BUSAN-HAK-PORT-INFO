# 🎨 부산항 스마트 작업 가이드 — 디자인 시스템 가이드

> 이 문서는 앱 UI의 **시각 언어(색·간격·타이포·형태·움직임)** 를 코드와 1:1로 맞춘 단일 기준입니다.
> 토큰 표는 `npm run tokens:docs` 로 자동 생성되므로, 문서와 실제 화면 코드가 어긋날 수 없습니다.

| 항목 | 값 |
| --- | --- |
| 기준 파일 | `scripts/design-tokens.mjs` (토큰 정본) |
| 적용 대상 | `public/css/app.css` (토큰 정본 블록 최상단 `:root`, 런타임 정본) · `public/admin.html` (부분 집합) |
| 이전 구조 | (2026-10-17 A-1 이전) 인라인 `<style>` 정본 + `css/app.css` 미러 — A-1 분리 이후 `css/app.css` 가 정본이 되고 index.html 은 마크업만 남음 |
| 자동 검증 | `scripts/design-tokens.test.mjs` (12개 테스트) · CI `npm run check` |

## 2. 설계 원칙

1. **단일 소스(Single Source of Truth)** — 색·간격·크기·그림자의 원시값은 `scripts/design-tokens.mjs` 에만 존재합니다. 화면 코드는 `var(--토큰)` 만 참조합니다.
2. **무회귀(Migration Safety)** — 토큰화는 값을 **바꾸지 않는 것**이 기본입니다. 레이아웃에 영향을 주는 값(간격·행간·굵기·Z축)은 *정확히 일치*할 때만 치환하고, 스냅은 페인트 전용 속성(라운드 ≤1px)과 서브픽셀 타이포(≤0.02rem ≈ 0.32px)로 제한합니다.
3. **의미 기반 이름** — 팔레트는 명도·채도 등급(`--n-*`, `--blue-*`, `--orange-*`), 역할은 시맨틱 토큰(`--primary`, `--bg-color`, `--text-sub`, `--border`)이 담당합니다. 화면 코드는 시맨틱을 우선 사용합니다.
4. **다크 모드는 시맨틱만 교체** — 팔레트(원시값)는 다크 모드에서도 변하지 않고, `--primary` 등 역할 토큰만 `body.dark-mode` 에서 재정의합니다.
5. **회귀는 CI가 막는다** — 하드코딩 재유입, 미정의 변수 참조, 토큰 정본 불일치, 스케일 이탈, 인라인 스타일 재유입(`app-split.test.mjs`)은 테스트 실패로 즉시 차단됩니다.

## 3. 작업 명령어

| 명령 | 설명 |
| --- | --- |
| `npm run tokens:apply` | 토큰 정의를 `css/app.css` 정본 블록에 반영하고, 하드코딩 값을 토큰 참조로 치환합니다. (멱등 — 여러 번 실행해도 안전) |
| `npm run tokens:check` | 파일을 수정하지 않고 정합성만 검사합니다. 불일치 시 종료코드 1. |
| `npm run tokens:docs` | 이 문서의 **토큰 부록(부록 A) 표를 자동 재생성**합니다. |
| `npm run check` | 타입체크 + 구조 검증 + 토큰 검증 + 전체 테스트(85개)를 한 번에 실행합니다. (CI와 동일) |

> 💡 새 색·크기·간격이 필요하면 **화면 코드가 아니라 `scripts/design-tokens.mjs` 에 토큰을 추가**한 뒤 `npm run tokens:apply` 를 실행하세요.

## 4. 타이포그래피

- 구현 스케일은 조밀한 모바일 현장 화면을 위해 **17단계 미세 래더**(`--fs-1` ~ `--fs-18`)를 유지합니다.
- **신규 코드는 아래 8단계 표준 래더만 사용**합니다(중간 단계는 기존 화면 무회귀용).

| 표준 단계 | 토큰 | 값 | px | 용도 |
| --- | --- | --- | --- | --- |
| 1 | `--fs-3` | 0.68rem | 10.9 | 배지·각주·단위 표기 |
| 2 | `--fs-5` | 0.75rem | 12.0 | 표 헤더·라벨·칩 |
| 3 | `--fs-6` | 0.80rem | 12.8 | 보조 본문·메타 정보 |
| 4 | `--fs-8` | 0.90rem | 14.4 | 목록 항목 |
| 5 | `--fs-9` | 0.95rem | 15.2 | **본문(기본)** |
| 6 | `--fs-12` | 1.10rem | 17.6 | 섹션 소제목·강조 수치 |
| 7 | `--fs-15` | 1.32rem | 21.1 | 카드 제목·합계 금액 |
| 8 | `--fs-17` | 1.85rem | 29.6 | 대시보드 KPI·히어로 숫자 |

- 굵기는 5단계(`--fw-medium` 500 → `--fw-black` 900)만 사용하며, 본문 강조는 `800`, 헤더는 `900` 을 기본으로 합니다.
- 행간은 `--lh-tight`(1.2, 한 줄 라벨) / `--lh-normal`(1.35, 본문) / `--lh-relaxed`(1.4, 장문) 3종을 권장합니다.
- 한글 가독성을 위해 `html, body` 는 `clamp(15px, 4vw, 17px)` 유체 본문 + `word-break: keep-all` 을 유지합니다.

## 5. 간격과 레이아웃

- 간격은 **2px 리듬**: `--sp-2 … --sp-20` (+ 컴포넌트 여백용 `--sp-24`, `--sp-32`).
- 권장 리듬: 요소 내부 최소 2~4 / 칩·배지 6~8 / 카드 내부 10~12 / 카드 사이 12~15 / 섹션 사이 18~24.
- 숏핸드 정리는 박스 모델상 완전 동치인 형태만 수행합니다: `12px 12px` → `var(--sp-12)`, `8px 6px 8px` → `var(--sp-8) var(--sp-6)`.
- `0` 은 관례상 원시값으로 유지합니다(불필요한 `--sp-0` 참조 금지).
- 터치 타깃은 최소 **44×44px**, 하단 고정 내비게이션은 `max(65px, safe-area + 55px)` 를 유지합니다.

## 6. 색상

- **뉴트럴 램프** `--n-000`(흰색) → `--n-1000`(검정) 17단계로 배경·테두리·텍스트를 모두 커버합니다.
- **브랜드** 딥 네이비 `--navy-900 (#0a1b3f)` + 액션 블루 `--blue-600 (#2563eb)`, 다크 모드 강조는 `--blue-400 (#60a5fa)`.
- **상태색** 성공 `--emerald-*` / 경고·주의 `--orange-*`, `--amber-*` / 위험 `--red-*` / 정보 `--sky-*`.
- 시맨틱 매핑: `--primary`(주요 버튼·강조), `--bg-color`(화면 배경), `--card-bg`(카드), `--text-main`(본문), `--text-sub`(보조), `--border`(구분선), `--danger`/`--success`/`--warning`/`--info`(상태).
- **2회 이상 반복되는 하드코딩 색상은 CI에서 차단**됩니다. 즉, 새로 등장한 색은 반드시 팔레트에 등록해야 합니다.
- 1회성 예외 색상(약 18종)은 부록 B의 정리 대상 목록을 참고하세요.

## 7. 형태 · 고도 · 모션

- **라운드**: `--radius-xs`(4) 인풋 내부 → `--radius-sm`(6) 칩 → `--radius-md`(8) 버튼·소형 카드 → `--radius-lg`(10) 기본 카드 → `--radius-xl`(12) 패널 → `--radius-2xl/3xl`(14/16) 모달 → `--radius-pill`(999) 배지.
- **고도(Elevation)**: `--shadow-elev-1`(헤더) → `elev-2`(떠 있는 칩) → `elev-3`(드롭다운) → `elev-4`(모달·팝업) → `elev-up`(하단 내비게이션). 같은 평면에서는 그림자를 하나만 사용합니다.
- **포커스 링**: `--shadow-focus-ring`(3px) / `--shadow-focus-light` / `--shadow-focus-dark`(모달 내부)를 재사용합니다.
- **모션**: `--dur-fast`(0.15s, 호버·탭 피드백) / `--dur-base`(0.2s, 색·테두리 전환) / `--dur-slow`(0.3s, 시트·그래프). 등장 애니메이션은 `@media (prefers-reduced-motion: reduce)` 에서 반드시 비활성화합니다.
- **Z축**: `--z-content`(2) → `--z-sticky-head`(20) → `--z-header`(100) → `--z-sticky-foot`(950) → `--z-ticker`(999) → `--z-bottom-nav`(1000) → `--z-visitor-badge`(2500) → `--z-modal`(3000) → `--z-toast`(5000) → `--z-hover-menu`(9999). 새 레이어를 추가할 때는 사이 값이 아니라 **이 사다리의 순서를 재사용**합니다.

## 8. 접근성 체크리스트

- 터치 타깃 최소 44×44px, 주요 버튼 높이 52px(근무일지 3버튼 동일 크기 규칙 유지).
- 본문 텍스트는 `--text-main`(라이트 대비 15:1 이상), 보조 텍스트는 `--text-sub`(4.5:1 이상) 범위에서만 사용합니다.
- 상태를 색만으로 전달하지 않습니다(아이콘·문구 병기) — 예: 경고 배지에 텍스트 라벨 포함.
- 포커스 표시를 제거하지 않고 `--shadow-focus-*` 로 대체합니다.
- `@media (prefers-reduced-motion: reduce)` 에서 애니메이션을 중지합니다.
- iOS 안전영역(`env(safe-area-inset-*)`) 처리를 유지합니다.
